# BookKit v2 admin UI — checklist

1. **Shell** — done. `app/admin/layout.tsx`: login gate, nav (Overview/Bookings/Event types/Availability/Brands/Analytics/Settings), `AlertBanner` (open alerts + Resolve), opportunistic `drainJobs({budgetMs:3000})` on every load, logout + sign-out-everywhere.
2. **Overview** — done. `app/admin/page.tsx`: health() checklist w/ fix links, today/upcoming lists, needs-attention count + link, "Run checks now" (`/api/admin/tick`), pause switch (`/api/admin/pause`).
3. **Bookings** — done. `app/admin/bookings/`: tabs (Upcoming/Past/Cancelled/Needs attention via `lib/admin/needs-attention.ts`), search + type filter, CSV export. Detail page: all fields, audit log, jobs w/ per-job Retry, actions (cancel w/ notify+refund toggles, reschedule w/ live-slot helper + free-form override, no-show toggle, retry calendar, refund, resend email).
4. **Event types** — done. `app/admin/event-types/`: reorder (up/down), duplicate, active toggle; editor covers every MeetingType field (brand/schedule, duration+extra durations, window types, notice/increment/buffers, limits, all 6 location kinds, all 6 question types, guests, redirect, confirmation note, cancel/refund policy, reminders/follow-up, secret, color). Live preview iframe of `/embed/<slug>`. Single-use links CRUD. `/admin/meeting-types` redirects. `lib/meeting-type-input.ts` rewritten for v2 with server clamping.
5. **Availability** — done. `app/admin/availability/`: schedules CRUD (weekly hours w/ multi-range + copy-to-Mon–Fri, date overrides, default), troubleshooter (event type + date -> per-slot reason incl. busy calendar/booking source) via `lib/availability.ts#explainDay`.
6. **Brands** — done. `app/admin/brands/`: CRUD, link to `/u/<slug>`.
7. **Share** — done. `components/admin/SharePanel.tsx` (used in editor + `/admin/share/[slug]`): UTM builder, direct link, popup/inline/badge/iframe/React/Calendly-drop-in/link-in-bio/email-signature snippets (matches `docs/EMBED-PROTOCOL.md`), QR PNG/SVG via `/api/admin/qr`. Every box has a top-right copy button (`components/admin/CopyButton.tsx`).
8. **Settings** — done. Google status + reconnect link, destination/conflict calendar picker (`listCalendars`), host profile, email status, alert channels (`ALERT_EMAIL`/`ALERT_WEBHOOK_URL` + send-test), cron status + exact URL, webhook endpoints CRUD (secret shown once, send-test signed delivery), API keys (shown once, sha256 hash at rest, revoke), data export/delete-by-email, env checklist.
9. **Analytics** — done. `app/admin/analytics/`: 7/30/90d funnel per type (views→slot→booked, conversion%), bookings by source (bar list), revenue (paid − refunded), cancellations/no-shows. Plain HTML/CSS, no chart lib.

## Not done / out of scope this pass
- Drag-and-drop reorder — shipped as up/down buttons instead (ponytail: same outcome, no DnD lib).
- Reschedule helper's slot list doesn't exclude the booking's own current time (see `app/api/admin/bookings/[id]/slots/route.ts` comment) — cosmetic only, the host can still type the time directly.
