# Code of conduct

Be decent. This is a small project maintained by one person in their own time.

**Expected:** patience, good faith, and specifics. A bug report that says what
you did and what happened is worth ten that say it is broken.

**Not welcome:** harassment, personal attacks, demanding free support, or
treating a maintainer's time as something you have bought.

Issues and pull requests that break this get closed. Accounts that keep at it
get blocked. Report anything that needs attention to the maintainer through
[a private security advisory](https://github.com/nchemb/bookkit/security/advisories/new),
which is the only private channel this repo has.

That is the whole policy.
